# Threadline Roadmap

The roadmap expresses product sequencing, not detailed implementation tasks.

## M0 - Architecture Foundation
Status: ACTIVE

Goals:
- establish canonical North Star
- establish architecture boundaries
- establish decision log
- establish multi-agent execution process
- establish task dependency system

## M1 - Capture and Semantic Foundation

Goals:
- persistent CaptureRecord
- text capture
- voice capture interface placeholder
- interpretation pipeline
- basic semantic object model
- confidence and provenance
- review flow

Exit condition:
A user can capture an unstructured thought, preserve the original expression, receive an interpretation, review it, and persist confirmed semantic meaning.

## M2 - Core Execution Objects

Goals:
- Ideas
- Actions
- Projects
- Commitments
- CalendarEvents
- attached reminder instructions
- relationships and dependencies

Exit condition:
Confirmed semantic objects can participate in a coherent relationship graph without losing capture provenance.

## M3 - Today and Commitment Calendar

Goals:
- commitment calendar
- Today's commitments
- manually confirmed actions
- basic morning digest

Exit condition:
The system can answer what is fixed today and what confirmed work is available.

## M4 - Foundational Canvas

Goals:
- infinite pan/zoom
- text nodes
- shapes
- containers
- connectors
- free positioning
- persistence
- semantic linking without destroying original geometry

Exit condition:
The canvas functions as a genuine thought-input system rather than merely a presentation surface.

## M5 - Adaptive Planning

Goals:
- urgency
- deadlines as constraints
- effort
- attention load
- strategic importance
- dependencies
- resource constraints
- plan recalculation
- manual pinning

Exit condition:
Threadline can recommend when work should occur while preserving hard commitments.

## M6 - Intelligent Organization

Goals:
- emergent idea grouping
- context discovery
- project association
- progressive taxonomy
- resurfacing

## Future

- ROI modeling
- deeper resource allocation
- people/capacity planning
- richer automation
- autonomous planning under explicit user constraints
