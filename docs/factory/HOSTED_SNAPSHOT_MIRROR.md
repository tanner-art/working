# Phone dashboard snapshot setup

This is a one-row mirror, not a second Factory Registry. The Mac publishes a signed, gzip-compressed, sanitized projection every three hours. The phone's Settings → Open agent dashboard button opens `/dashboard`; Refresh reloads only the latest published copy. It does not wake or contact the Mac. The page visibly marks snapshots older than 3½ hours.

1. Apply `scripts/factory_registry/hosted_snapshot.sql` to the Threadline Supabase project through the reviewed migration process. The table has RLS enabled and no `anon` or `authenticated` grants. Do not put Factory data in `threadline_account_data`.
2. Configure the actual Threadline Vercel project with server-only `FACTORY_CONTROL_ALLOWED_USER_IDS`, `FACTORY_CONTROL_SUPABASE_SERVICE_ROLE_KEY`, `FACTORY_CONTROL_PUBLISH_TOKEN`, and `FACTORY_CONTROL_PROJECTION_SIGNING_SECRET`. Keep the existing Supabase URL and client auth settings. Never expose these secrets in browser variables or logs.
3. On the Mac, store the publisher token and signing secret in Keychain as `threadline-factory-dashboard-publish-token` and `threadline-factory-dashboard-signing-secret` (or supply the corresponding environment variables in a protected local process). Run `python3 -m scripts.factory_registry.publish_control_snapshot --database "$REGISTRY_PATH" --endpoint "https://<Threadline-host>/api/factory-control"` once. Verify that the returned website snapshot reports the same Registry revision and generated time. Do not print the snapshot or credentials.
4. Fill the four non-secret placeholders in `scripts/factory_registry/launchd.dashboard-snapshot.plist.template` with the installed repository path, Python path, authoritative Registry path and public HTTPS endpoint. Install it as the user's `com.threadline.factory.dashboard-snapshot` LaunchAgent only after the hosted endpoint passes the first publication. It runs at login and every 10800 seconds (three hours), reading the two secrets from Keychain. Keep it independent from the Factory runner; Mac sleep/offline simply makes the last copy stale.
5. On the phone, open Settings → Open agent dashboard, sign in, tap Refresh, and verify the displayed Registry revision against the Mac. Check that an unauthorized account cannot read it and that a missing/bad publisher signature does not replace the row.

Do not activate this bridge by configuring secrets alone. Merge and deploy the reviewed code and apply the single-row table first. A previous dashboard deployment using the loopback HTTPS-transport design will not read this mirror.
